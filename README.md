## ✨ Fonctionnalités

- 🎯 **Suivi automatique** — dès que la personne change de salon vocal, tu es déplacé avec elle, instantanément.
- 🖱️ **Un clic droit suffit** — l'option s'ajoute directement au menu contextuel des utilisateurs.
- 💠 **Indicateur visuel** — anneau bleu autour de l'avatar et flèche ➤ sur la personne suivie dans la liste vocale.
- 🔄 **Mises à jour automatiques** via BetterDiscord.

## 📦 Installation

### 1. Installer BetterDiscord

Télécharge et lance l'installeur depuis **[betterdiscord.app](https://betterdiscord.app/)**, choisis **Install BetterDiscord**, sélectionne ton Discord puis valide. Discord redémarre avec un nouvel onglet **BetterDiscord** dans les paramètres.

### 2. Télécharger le plugin

Clique sur le bouton violet en haut, ou directement ici :
**[FollowUser.plugin.js](https://github.com/Sweezyskz/FollowUser/releases/latest/download/FollowUser.plugin.js)** (téléchargement direct)

> Le fichier doit s'appeler exactement `FollowUser.plugin.js`.

### 3. Placer le plugin dans le dossier

Dans Discord : **Paramètres → BetterDiscord → Plugins → Open Plugins Folder**
Glisse `FollowUser.plugin.js` dans le dossier qui s'ouvre.

Chemin manuel si besoin :
```
%APPDATA%\BetterDiscord\plugins
```

### 4. Activer

Retourne dans **Paramètres → Plugins**, trouve **Follow User** et active le toggle. C'est prêt.

## 🎮 Utilisation

| Étape | Action |
|---|---|
| **1** | Rejoins n'importe quel salon vocal |
| **2** | Clic droit sur la personne à suivre (liste vocale, membres ou MP) |
| **3** | Coche **Follow User** en bas du menu |
| **4** | Quand elle change de vocal, tu la suis automatiquement |

Pour arrêter : clic droit → décoche **Follow User**.
Une seule personne peut être suivie à la fois ; en suivre une nouvelle remplace l'ancienne.

## ❓ FAQ

**L'option n'apparaît pas dans le clic droit ?**
Vérifie que le plugin est bien activé (toggle vert) dans Paramètres → Plugins, puis `Ctrl+R` pour recharger Discord.

**Je ne suis pas déplacé ?**
Tu dois avoir la permission de rejoindre le salon où va la personne. Les salons pleins ou privés ne sont pas accessibles.

**Est-ce que c'est autorisé par Discord ?**
Comme tout client mod, BetterDiscord n'est pas officiellement supporté par Discord. Utilise-le en connaissance de cause.
